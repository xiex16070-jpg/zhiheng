# 知衡 Agent 工作台升级（2026-11-06）

本轮从 `codex/audit-fixes@1be5ca9` 推进，按用户要求把项目组织、文件阅读、模型主动执行和可审阅的权限整合进工作台。产品名称改为“知衡 · Agent 工作台”，定位为研究、创作与执行；知识库与逻辑验算仍保留。本记录描述实际实现，不将技术栈自由等同于关闭身份验证或跳过用户批准。

## 1. 项目与会话

左侧“项目”标题旁的加号调用本机文件夹选择器。选中目录后登记为独立项目，保留项目名称、目录身份与当前选中状态；每个项目下显示自己的会话。项目可折叠、切换、重命名或移除，项目旁可直接新建会话。

- 默认工作区继续存在；旧单工作区绑定兼容迁移为版本 2 项目登记，不复制或移动用户目录。
- 登记文件为 `data/workspace-bindings/<userId>.json`，按属主隔离；最多 50 个外部项目。目录以真实路径、设备／文件身份及创建时间校验，移走或卸载后显示不可用，不静默跳转到同名新目录。
- 会话新增 `workspaceId`，旧会话优先按同属主最后任务的项目记录迁移，无可用记录时归入 `default`。MySQL 采用幂等字段迁移，文件存储继续兼容旧结构；新会话与续接会话保留项目身份。
- 新请求、恢复和文件工具入口核对项目；运行中的任务阻止切换。等待审批期间即使选择改变，旧任务也不会写入另一个项目。
- 移除项目仅撤销登记，保留文件与会话；侧栏显示“已移除的项目”，重新添加同一文件夹后可恢复关联。文件预览和下载旧 URL 在登记移除后失效。
- 项目列表当前返回最近 300 条会话，不声称提供无限历史分页。系统文件夹选择器目前为 Windows 本机能力；远程请求不能借项目 API 指定任意磁盘路径。

主要 API：

| 方法与路径 | 作用 |
|---|---|
| `GET /api/projects` | 当前项目、注册项目与所属会话；远程响应不带本机根路径 |
| `POST /api/projects`，`{action:"choose"}` | 通过本机选择器添加项目 |
| `POST /api/projects/:id/select` | 切换项目；运行任务占用时返回冲突 |
| `POST /api/projects/:id/rename`，`{name}` | 修改显示名称 |
| `POST /api/projects/:id/remove` | 撤销登记，保留文件与会话 |

项目变更需本机、签名身份、同源与 `x-workspace-picker` 请求标记，成功操作写审计。实现：`workspace-selection.mjs`、`projects-api.mjs`、`store.mjs`／`db.mjs`、`src/ui/projects.js`。

## 2. 渲染后的文件预览

文件卡片和工作区中的“预览”打开右侧阅读面板，“新窗口”打开 `/preview.html?path=…&workspace=…`。阅读面板支持多个文件标签、重新加载、下载与渲染／源码切换；标题、目录和文件归属始终可见。打开预览不改变活动项目，也不向文件写回内容。

| 格式 | 实际预览 |
|---|---|
| Markdown | 标题目录、段落、表格、引用、列表、代码块、同项目相对链接与图片；可切换源码 |
| PDF | 浏览器原生 PDF 阅读器，支持范围请求；真实生成 PDF 已核对渲染正文与阅读工具栏 |
| PNG/JPEG/GIF/WebP/AVIF/SVG | 图片阅读；SVG 以图片和受限响应策略呈现，不运行脚本 |
| CSV/TSV | 最多 200 行、50 列的表格；可查看原始文本 |
| 代码、JSON、普通文本 | 源码／文本查看，保留换行，内容不会执行 |
| DOCX/XLSX/PPTX/Notebook | 有界文本提取，明确标为“文本预览／提取文字”；不承诺与 Office 完整排版、公式计算或交互一致 |
| HTML | 静态清洗预览；脚本、表单和外部资源不执行；完整原件可下载 |
| 其他二进制 | 明确提示下载后使用对应应用打开 |

`GET /api/workspace/preview` 返回描述与清洗后的内容，`GET /api/workspace/asset` 提供图片、PDF 或附件下载。两者使用 `path` 与 `workspace`；`download=1` 强制下载。路径必须属于当前用户已登记项目，逐段拒绝穿越、保留目录、软链接／junction 和硬链接。非默认本机项目还必须满足本机签名身份检查，即使当前活动项目已经切回 default 也不能通过远程请求读取。

文本预览读取前 200 KB，Office 提取输入上限 25 MiB；截断有提示。Markdown 相对文件链接保留原项目标识，图片仅取同项目资源，不自动访问外部图片或追踪地址。预览窗口按原属主认证，不能因为知道文件名和项目 ID 就读取他人文件；所有响应均不缓存。

实现：`src/server/artifact-preview.mjs`、`src/ui/artifact-preview.js`、`artifact-viewer.js`、`src/styles/artifact-preview.css` 和 `preview.html`。

## 3. 模型主动安排任务

`delegate_task` 保持有界只读子代理，并在模型可见能力中明确呈现。新工具 `start_background_task` 让模型直接安排可独立完成的耗时工作；用户不必先点击“后台运行”。手动入口仍可使用。

| 工具 | 行为 |
|---|---|
| `delegate_task` | 一次提交至多 3 个自包含的只读研究目标，子代理不写文件、不批准、不继续委派；父任务核对返回证据 |
| `start_background_task` | 新建独立会话与任务，继承项目、资料范围、研究策略和文件权限；返回真实任务入口 |
| `get_background_task` | 查询当前项目后台状态、摘要与产物；留空 task_id 列出最近任务 |
| `cancel_background_task` | 停止当前用户、当前项目的在途后台任务；不撤销已完成的文件或外部操作 |

每个父任务最多启动两个子后台，次数随 checkpoint 持久化；子后台主模型调用上限为 `min(5, MAX_TOOL_ROUNDS + 1)`，继续使用既有 AUX 预算，不能再创建后台或子代理。后台运行器另有全局 3 个、每用户 2 个在途任务与 30 分钟运行上限。排队状态不能被描述成任务已完成。

后台任务需要批准或澄清时仍暂停，恢复仍校验项目、来源范围和权限。通知只报告执行状态，不能被当作用户回答、批准或新指令。服务停止时任务不会继续运行；重启记录中断，不自动重放写操作。凭据不写入后台任务持久化记录。

实现：`agent-background.mjs`、`background-tasks.mjs`、`orchestrator.mjs`、工具 schema 与提示词；界面显示真实后台状态和关联会话。

## 4. 文件修改权限

输入区“项目权限”与设置中的“文件修改权限”共用服务端持久化状态。权限归属用户与项目，默认 **ask／逐次确认**；模型无权自行提升权限。

| 模式 | 文件行为 | 其他操作 |
|---|---|---|
| `ask` 逐次确认（默认） | 创建、替换、patch 及派生产物写入前发出审批 | 保留命令、外部工具等各自权限 |
| `trusted` 信任此项目 | 用户明确允许当前项目的文件写入；仍检查路径、内容版本及工具约束 | 不自动批准命令、外发、插件或其他项目 |
| `read_only` 只读浏览 | 拒绝模型文件写入 | 同时禁止命令和可能产生副作用的插件操作 |

统一写入覆盖文本写／改、文档与可视化生成、PDF 填表／拆分／合并、Notebook 修订、LaTeX 编译、Zotero 导出及图像产物。审批卡显示目标、操作、前后文本差异或派生产物说明；长内容显示截断提示，不能误称展示了全部文件。

审批记录绑定真实用户、任务、项目、权限版本、规范化完整参数摘要、目标及输入文件版本。生成或等待批准期间文件、权限或输入发生变化，旧批准不能继续落盘；最终写入再次核验，用户需重新读取并发起变更。拒绝后不执行对应写入，任务可继续处理其他可完成事项。

API 为 `GET/POST /api/file-permissions`，保存字段 `{workspaceId,revision,mode}`。仅本机签名身份与同源设置请求可修改；配置损坏时拒绝模型写入并保留文件。状态保存在 `data/file-permissions/<userId>.json`。命令执行的工作区约束不是操作系统沙箱，不能把“信任项目”描述成任意系统全权限。

实现：`file-permissions.mjs`、`file-write-context.mjs`、`workspace.mjs`、`orchestrator.mjs`、`src/ui/file-permissions.js`。

## 5. 美术与动效

整体布局采用左侧项目、中间对话、右侧产物阅读；品牌文案、首页任务入口和界面信息层级围绕工作台重新组织。冷瓷白与深墨蓝构成明暗主题，青绿为交互强调；原创轨道品牌标识与透明 3D 图形替代旧书本单一主题。图像来源与实际尺寸见 [视觉资源说明](../assets/README.md)。

Motion 处理组件入场与状态反馈，GSAP 承担开屏序列，按钮使用浏览器原生动画反馈。开屏每次浏览器会话最多自动播放一次，约 1.65 秒内结束；可跳过，Escape／Tab／开始交互可结束，也可在设置关闭或重播。动画不阻塞启动和模型请求，减少动态效果时停止非必要动画，不为每个流式 token 重播入场。

本轮用户明确准许大幅更改、使用其他高级语言和框架，宪章 VII 已更新为产品驱动的技术选型。当前实现使用现有模块体系不等于未来只能使用原生前端；技术与技能建议不能覆盖用户授权。权限机制、私有数据边界与事实标记继续保持可检查。

## 7. 产品体验与设计规范（2026-11-08）

状态：当前实现；实施基线 `codex/audit-fixes@eb856f2`。本节由用户确认的产品体验审查方案推进，代码与验收记录为事实依据，前六节为原实施记录。后续修改先核对实际 HEAD。验收版本、命令、输入和资源哈希见 机器记录。本轮未调整模型、检索排序或文件/网络授权。

### 7.1 三个阶段与真实行为

- 开始：顶栏双模式和各自配图继续使用。研究卡片进入知识模式、保留草稿并聚焦主输入；创作/项目卡片进入 Agent，只在草稿为空时填写示例。资料管理仍在知识库工作台。输入区显示当前项目与研究范围，联合研究显示实际保存的开关和权重；权限保持可见，技能、后台与语音收纳到可用键盘打开/关闭的“更多操作”。未配置模型时就地引导连接。
- 范围：摘要复用 `preferenceStore`、项目侧栏和所选文档。排队研究保存范围签名；派发前若范围已改变，暂停并提示用户回填核对，不自动扩大范围。签名不是授权凭据；服务端仍执行属主、学科/分区/文档与任务约束。
- 执行：停止、失败、截断和缺少回答正文分开。断流通过 GET task 核对真实终态，包含 cancelled。失败卡核对后提供恢复；恢复使用当前模型，服务端重新检查原任务、预算、项目、审批与权限。已停止/回退任务不提供恢复。修改后重新发送只回填草稿，不发请求。
- 过程：只显示发生过的事件；折叠摘要注明等待确认和实际异常数。工具异常与最终回答交付分别呈现。没有固定百分比、预设耗时或模型内部思考展示；IRCoT/ToT 相关性不解释为真值概率。
- 阅读：回答、引用来源、逐句审核、模型推断和规则证明沿用已有折叠，关键截断/冲突与审批保持可见。阅读器只显示实际解析页码；没有页映射时写“未提供页码”，字符区间不推算页码。403/404 同样显示“资料不存在或不可访问”，失败可就地重试并返回答案。重试保留引用焦点；旧响应不能覆盖新来源。
- Markdown：聊天增加表格与普通 HTTP(S) 链接，代码和 HTML 始终转义。禁用活动协议、带凭据 URL、图片自动加载和原始 HTML。这是受控 Markdown 子集，不等价完整 GFM；文件预览继续使用既有服务端清洗。流式只重画未完成块，完成节点不反复动画。

### 7.2 精简设计规范

变量唯一入口为 `src/styles/tokens.css`，`experience.css` 只组合语义变量，不另立主题。现有短变量保留为兼容别名。

| 项目 | 约定及用途 |
|---|---|
| 颜色 | 保留冷瓷白 `--ui-paper:#f8f9fc`、深墨蓝 `--ui-ink:#182b3b`、次级 `--ui-muted:#607084`、青绿 `--ui-accent:#1d6e77`；暗色由相同变量覆盖。警告/危险配文字与图标，不用颜色宣称事实为真 |
| 字体 | 沿用 sans/serif/mono 字体栈，不安装专有字体。UI 主标签14px、次级13px、元数据12px，答案16px/1.8；标题20/24/28px层级。12px下限是检查项，不等于无障碍认证 |
| 间距 | space-1/2/3/4/6/8 对应4/8/12/16/24/32px。控件内部紧凑，区块间留白，避免逐组件任意定值 |
| 宽度 | content-width 900px；桌面消息内边距保留约720–800px正文。表格/代码局部滚动；小屏页面本身不能横向溢出 |
| 形状 | 控件12px、紧凑操作8px、面板20px，常规1px边框。阴影主要用于浮层/主要动作，避免所有组件都有厚重浮雕 |
| 控件 | 局部任务一个主要动作，辅助操作轻量呈现。重要触控目标44px；输入标签常驻，聚焦用2px强调色轮廓，错误紧邻字段并通过 aria-describedby 关联 |
| 反馈 | 未保存/保存中/成功/失败不同文案；真实总量才显示比例。失败保留内容和可执行下一步；已配置、连接通过、本次授权、执行完成分别表达 |
| 动效 | 沿用组件160–210ms、面板260ms和现有 Motion/GSAP。仅新增节点/真实状态变化触发，系统减少动效时取消移动；开屏沿用现状，不阻塞审批和输入 |
| 键盘 | 原生 details/summary；真正标签页采用关联面板、单一 Tab 停靠点、方向键/Home/End及 Enter/Space 激活。学习页复用 tabs.js，慢接口不因移动焦点自动请求 |
