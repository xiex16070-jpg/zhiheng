# 联合研究

## 操作与证据路径

提问框下的“联合研究”和设置中的同名卡片控制同一份持久化偏好。默认关闭，`localWeight` 默认 70。预设按钮和键盘可操作的滑杆支持 10–90% 的本地目标比例，步长为 10。保存失败会回读并恢复已确认的选择；发送问题沿用现有偏好保存等待机制。

开启后依次执行本地检索、用户选择的 ReAct/IRCoT/ToT 本地研究策略、受控外部发现与材料获取、证据融合、模型工具循环、引用检查。外部查询只从本次用户问题生成，不包含知识库片段、历史、记忆或技能。中文计算机术语有有限的确定性英文映射，没有使用模型把私人材料改写成联网查询。复杂或其他领域的中文查询可直接补充英文检索术语。

本地范围仍按用户和分区过滤。模型不能通过 `update_preferences` 开启或改变联合研究。通用 `web_search`、`web_fetch`、`scholar_search` 在此模式下不提供给模型，执行层也会拒绝；模型仍可读取、核对系统已取得的外部证据，并补检本地材料。外部检索目前只做一轮，不使用 IRCoT/ToT 的中间私有摘录发起公共追检。

## 来源与范围

在导入结果或引用原文中可复核已保存论文的出版状态。先核对显示的 DOI，再选择允许联网复核。系统仅把这个 DOI 发送给已启用的 Crossref、Europe PMC 和 OpenAlex。导入文档使用开头单列的 DOI 元数据，缺少明确标识时显示“出版状态未知”。可随时在原文中停止后续复核。

每次查询按用户与 DOI 缓存，保留来源、公告类型、查询时间和有效期。常规结果有效 24 小时，状态未知或接口失败时为 5 分钟。已授权的 DOI 在再次打开或新回答引用且缓存过期时复核。展开来源可核对各接口记录。有撤稿、更正、来源冲突、过期或未知状态时，引用清单上方会提示。原始资料与引用保留。Crossref 通过原文的 `updated-by` 识别公告。“已查来源未报告撤稿或更正”仅描述已查索引的结果。[Crossref 对 Retraction Watch 数据范围的说明](https://www.crossref.org/documentation/retrieve-metadata/retraction-watch/) [Crossref 原文 DOI 查询示例](https://community.crossref.org/t/deprecating-retraction-watch-annotations-in-the-labs-api/15884)

| 通道 | 实际用途 | 内容边界 |
|---|---|---|
| OpenAlex | 跨学科论文元数据、摘要词序恢复、DOI | 无摘要不进入证据；索引收录不证明已同行评审；过滤已标记撤稿 |
| Europe PMC | PubMed/PMC 等记录及摘要 | 预印本独立标记，拒绝已标记撤稿和无摘要结果 |
| arXiv | 可选预印本摘要和版本链接 | 标注发表/更新日期，关闭预印本时不请求 |
| 官方网站 | 政府、国际机构、技术文档、标准和出版机构 | 已配置搜索后按域名筛选，继续读取页面；搜索摘要不能直接变成证据 |
| 参考与新闻 | 综合模式中的补充材料 | 标为二次资料，不能仅凭网站声誉宣称结论已验证 |

受控域名位于 `src/server/authority-policy.mjs`，覆盖用户提出的政府/国际组织、IEEE/ACM、Nature/Science/Lancet、技术标准、中文学术入口和高编辑标准新闻等类别。Google Scholar、Semantic Scholar、Web of Science、Scopus 在本版没有独立适配器，不能把它们列为已接通的数据源。Wikipedia、Kaggle 和任意 GitHub 用户页面不作为权威证据入口。不得绕过登录、付费墙或验证码。

网站采用严格的主机/子域匹配，拒绝伪装域名、URL 凭据、非 HTTPS 和非标准端口。搜索端传 domain filter 或受控 `site:` 查询，响应再次过滤。读取前、每次跳转和缓存命中均检查来源策略，沿用已有 DNS/IP 固定与内网防护。外部请求具有时间、字节数、结果数和上下文摘录上限；用户取消会中断进行中的请求。

## 权重与可验证性

首先按相关程度筛选，再以来源类型、出版日期排序。只使用有实际内容且达到词面相关阈值的候选。外部来源之间及其与本地候选间按标识、链接、标题去重。每次默认选 6 条，最多 10 条；紧凑 Qwen 配置选 4 条，前三段就能看到两类来源。按权重分配配额，两侧都有资料时至少各保留一条。某侧不足时名额让给另一侧，并显示实际数量。首页选中的本地资料保持在候选中。

预印本、摘要和网页摘录显示各自范围，`review-unverified` 不应解释为已评审。来源信誉、论文数量、词面相关度均不是事实概率。提示要求关键结论优先对照 2–3 项独立研究或机构，指出冲突和缺口；结果元数据只统计实际引用的不同资料与来源，不宣称自动验证独立性或逐句蕴含。`semanticSupportVerified` 仍为 `false`。

任务保存冻结的联合研究设置、证据快照和来源状态。审批恢复不会重复外部检索。暂停期间设置改变则要求重新提问，避免按已撤销的联网设置继续执行。外部文本随用户任务和引用保存在本地存储中，阅读器使用当次快照，不会因为打开引用重新访问网站。Langfuse 新增 `retrieval.authority` 子轨迹，仅记录耗时、关联与结果类别，不发送问题、文档、来源 URL 或摘要。

## 服务配置

无需新增前端依赖。`SCHOLAR_SEARCH=1` 启用学术接口。本机可在 **设置 → 网站搜索 → OpenAlex** 保存免费 API Key，从 [OpenAlex 账户设置](https://openalex.org/settings/api) 获取。密钥通过 Authorization 发送，不进入来源 URL。匿名请求额度较低，HTTP 429 也可能来自每秒频率或账户日额度；增加 Key 不保证解除已耗尽的额度。采用 [OpenAlex 官方认证说明](https://help.openalex.org/api/authentication/)。`OPENALEX_API_KEY` 保留为尚未从界面保存配置时的兼容入口。

政府/机构/标准网页检索可直接在左下角 **设置 → 网站搜索** 配置 Tavily 和 Serper，已有 Bing 环境配置可继续读取。四张服务按钮还包含 OpenAlex 和 Europe PMC；每项独立保存、测试和启用。留空保存保留当前服务的旧密钥，移除只影响当前服务。多个网站引擎启用后并行请求、轮流取结果并按 URL 去重，一个引擎失败不会丢弃另一个的结果。网页正文读取是共享开关，保存立即作用于后续请求与新任务。

Europe PMC 使用 [EBI 官方 REST API](https://dev.europepmc.org/RestfulWebService)，**无需账号或 API Key**。HTTP 503、网络超时与返回 0 条资料要分开看：前两者表示未完成检索，不能解释成没有相关文献。学术请求对 502/503/504 最多重试一次；对 429/503 按 Retry-After 冷却，默认分别为 60/20 秒。成功查询按请求和凭据缓存五分钟，最多 32 项。设置中可以单独关闭不稳定的学术来源；其他通道继续工作。`SCHOLAR_SEARCH=0` 仍是学术检索的服务端总开关。

网站连接测试使用固定 NIST 查询，OpenAlex 使用 “retrieval augmented generation”，Europe PMC 使用 “machine learning”；不发送用户问题、文档或对话。结果只包含状态、数量、耗时与安全错误类别，不返回摘要或上游错误体。测试草稿不会覆盖配置，已保存密钥可在输入框留空时测试。每个签名会话每分钟至多五次。修改、测试和移除仅允许真实本机、匹配 Origin、自定义请求头与服务签名会话；远程界面只显示搜索配置状态。

设置保存在被 Git 忽略、不可静态下载的 `data/.web-search.json`。v2 采用随机 nonce、用途绑定的 AES-256-GCM，使用独立的 `data/.credential-key`；登录 `AUTH_SECRET` 轮换不再破坏已迁移的搜索凭据。启动时在旧签名密钥仍有效的条件下自动迁移 v1；旧凭据已无法解密时必须重新填写，不会暗中恢复环境密钥。**备份或迁移要同时保留配置文件与 `.credential-key`**。写入采用同步落盘、原子替换和配置版本，失败不改变原状态。读取、保存、测试均不回传密钥，浏览器不存搜索密钥；审计仅记录服务、状态、版本、测试结果与耗时。

同一数据目录只允许一个服务实例，避免不同端口中的旧进程各自缓存配置。Windows 使用命名管道，Linux 使用抽象 Unix socket；进程退出或被杀后由系统释放。不同数据目录仍可运行独立实例。启动器优先复用已有服务。

`WEB_SEARCH_PROVIDER=tavily|serper|bing`、`WEB_SEARCH_KEY` 和 `WEB_FETCH_ENABLED=1` 仍可作为未从界面保存时的兼容配置。本机保存的设置优先；关闭或移除密钥不会在重启后重新启用旧环境密钥。Tavily 使用服务端 Bearer 认证并传入 [include_domains](https://docs.tavily.com/documentation/api-reference/endpoint/search)；其他现有后端使用受控 `site:` 表达式并再次筛选返回域名。没有可用配置时，学术 API 可继续使用。选择“政府与机构”且网站搜索不可用时会明确无外部材料，不自动扩大到论文或任意网站。

## 验证

- Node 单元测试覆盖偏好校验、默认关闭、源白名单、假域名、跳转/缓存、超大响应、取消、去重、配额、预印本和元数据真实性边界。
- HTTP/SSE 测试使用真实服务器、用户隔离存储和明确的合成上游，覆盖三种研究策略、真实工具读取、外部引用持久化、未配置/离线降级、来源策略绕过、审批恢复，以及公共查询不含私有文档。
- `python scripts/ui-joint-research-smoke.py` 使用临时数据目录，验证五种窗口/主题组合、键盘比例调整、持久化、回读回滚、引用阅读、历史重载、减少动态效果和无横向溢出。该验收的模型和外部记录为合成夹具，不代表回答质量评测。
- 2026-11-05 本机实查 “Can retrieval augmented generation reduce hallucination?”：arXiv 取得 4 条合适摘要、Europe PMC 5 条，OpenAlex 返回 HTTP 429；网站搜索尚未配置。记录显示 partial，没有把限流当作成功。这是连接与证据获取检查，尚非真实模型语义质量基准。
- 2026-11-05 后续网站设置验收：新增五组窗口/主题的真实配置 API 操作、草稿测试隔离、失败恢复、禁用/移除、实时能力更新与空密钥回读。Node 测试覆盖加密与篡改、重启、原子写失败、版本冲突、CSRF/非本机请求、热生效和审计脱敏。本机真实 Tavily Key 已通过草稿测试、保存后的服务端测试与正式界面测试，NIST 查询均返回 1 条；本记录不包含密钥。
- 2026-11-05 本轮补验：真实 OpenAlex Key 的草稿测试、加密保存、留空测试均成功并返回 1 条；原 Tavily Key 保留且返回 1 条。Europe PMC 两个公开查询曾成功返回文献及摘要，后续又出现 15 秒超时，仍属间歇性上游/网络故障，没有将它记为已稳定修复。已移除同时运行、共享数据的 3000/3002 两个旧实例，统一到 3000。
