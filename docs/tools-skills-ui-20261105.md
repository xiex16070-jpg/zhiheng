# Tools、Skills 与按钮视觉整合核查

核查基线为48ccd01。本轮检查实际工具入口、提示词、分区与用户隔离、技能升级和真实浏览器行为，并完成相应修复。

## 整合质量与修复

工具和技能已接入现有编排器、schema、工作区与用户存储。主要遗漏集中在新增能力没有完整继承原有边界，以及提示词和实际可调用能力不一致。

| 问题 | 本轮结果 |
|---|---|
| 私人分区仍能通过学术搜索外发问题、历史搜索带入其他范围内容 | 从该任务实际工具集合移除，并在执行入口再次阻止 |
| 技能工具可在私人分区读取个人习得内容 | 自动发现与读取仅使用公开全局流程，保留普通范围的个人同名优先级。用户显式手选技能仍作为授权指令 |
| 工具开关关闭后仍向模型宣称可用 | 关闭 scholar 或技能功能时隐藏相应 schema，执行层保留防守。提示菜单与审批恢复使用实际工具名单 |
| 新工具取消、超大响应与文件读取界限不完整 | 预取消不请求网络，外部响应限制2MiB、禁止重定向、裁切返回条数，文档采用句柄复核及25MiB有界读取 |
| Europe PMC core字段与链接遗漏、arXiv错误Atom被误当文献 | 修正期刊字段、MED id/PMCID/source-id链接映射，识别Atom错误条目 |
| find_files 的双星目录匹配可能命中文件名后缀 | 修正目录边界并保留工作区隔离 |
| 技能截断后被称作“全文” | 明确片段与总长度，skill_view分页返回next_offset，末尾步骤可以继续读取 |
| 技能路由与内置库升级遗漏 | 改进引用核验和证据综述路由。仅在来源哈希可证实时升级全局副本，保留未知修改、归档、个人同名覆盖及使用状态 |
| 新工具在追踪中都被归为unknown | 加入受控工具名枚举，继续只记录受控元数据 |

技能说明不能扩张工具权限、跳过审批或被当作文献证据。发现技能仅在任务相关时进行，长技能按需分页。仓库分发24个流程技能。离线默认配置注册22个工具，部署时会根据功能开关和任务范围筛选。本地Qwen仍采用已评测的12工具紧凑配置，完整Agent工具面的新增能力不能据此假定已在8B模型上验证。

## 视觉和动效

主按钮使用玉色层次、细金图标，次按钮使用纸面与边框，统一侧栏、顶部、分段偏好、发送、关闭和弹窗动作。补齐触屏按压、键盘焦点、禁用与加载状态，修正玉色工作台关闭按钮的前景背景对比。

Motion mini负责新增消息、引用、实际步骤状态、偏好选择和弹窗的有限组件过渡。流式文本沿用增量绘制，不逐token播放入场。

GSAP负责工作台标题、推理图线和标签的进入序列，ScrollTrigger只绑定工作台内部滚动区域。关闭弹窗或切换减少动态效果时清理timeline和滚动触发器，并停用该实例拥有的全局滚动循环。装饰资源失败时保留可操作的原生界面。

| 本地构建资源 | 原始字节 | gzip参考字节 | 加载位置 |
|---|---:|---:|---|
| Motion mini | 8,442 | 3,286 | 支持动态效果时异步加载 |
| GSAP工作台 | 117,012 | 46,292 | 打开推演工作台时加载 |

资源在本地构建和托管，运行时不访问CDN。首屏不加载GSAP。系统减少动态效果时两份动画资源均不加载。静态服务未因本轮额外配置传输压缩，上表原始字节可用于估计直接传输量。

构建使用固定依赖版本，npm run build:ui生成资源及版权声明，npm run check:ui核对资源与源码一致性。CI执行同一核对。

## 验证

- 336项Node回归通过，覆盖真实HTTP审批恢复、租户与分区隔离、技能分页与旧安装升级。
- 桌面与手机、明暗主题的顶部/侧栏动作、原生单选键盘操作、真实偏好保存、来源阅读器和流式节点身份检查通过。
- 新增ui-effects-smoke.py实际加载动画包，检查懒加载、工作台切页、运行时减少动态效果、资源失败回退与真实规则执行。关闭后桌面、手机、减少动态效果和资源失败四组空闲帧均为0。
- 减少动态效果组没有请求动画库，资源失败组仍能运行规则验算。浏览器无未处理异常。

## 导航与配置后续调整

知衡推演、工作区和学习入口移到左侧工具栏，目录独立滚动，左下设置始终可见。设置整合模型接口、回答偏好、外观、学习记忆和监控，原偏好组件在设置打开时移入，关闭时归位，避免重复控件和保存状态分叉。

示例、记忆类型与画像更正改为原生单选按钮组。文献推理和规则验算的两个输入框均已删除。文献方法应用到主提问框，规则验算运行选定示例，示例代码默认收起且只读，自有程序可从主输入框提交。

研究问题按内容主题显示，清除原始导入文件名和悬浮提示。点击时隐藏传递focusRef，服务端在任何模型调用之前核验用户及当前分区，复用真实原文与引用定位。跨用户、分区外或缺失来源会被拒绝。审批暂停恢复保留已核验的来源。

真实浏览器检查覆盖手机抽屉焦点恢复、设置底栏在长目录滚动时位置固定、配置保存、单选键盘操作、旧缓存问题去文件名，以及首页卡片至POST请求的来源绑定。

## 外部服务实测范围

使用公开文献问题联网时，Europe PMC曾成功返回两条结果，随后复测返回HTTP503。链接映射修复由真实core契约的正反例验证，尚无修复后成功响应可作为质量证明。arXiv本机直连返回fetch failed，具体网络原因未定位。工具会明确返回失败，不伪造检索结果。这些记录不能等同于外部文献质量或模型回答质量评测。
