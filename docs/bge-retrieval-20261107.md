# 2026-11-07 真实 BGE 与词法检索对照

本轮运行了真实 `BAAI/bge-m3` 权重与本机 CPU 推理，不是模拟向量服务。部署和索引构建见 [部署记录](bge-deployment-20261107.md)。比较采用同一固定 Software Foundations 开放教材语料：712 个父片段、1685 个约600字符窗口，原文及偏移不改写。

## 预先固定的题与方法

`evals/bge-literature-cases.json` 在语义对照运行前冻结，LF SHA256：`610e640889d8c71031574d0f7ac29131ec0713342f48afc37556c0031f8cd0f9`。包括12个概念各一条中/英文问题，共24正例，另4个教材无法回答的领域/实时信息负例。

每个正例都有已核对的原文精确引文、父ref、章节、来源URL、MIT许可证与正文SHA。问题/标签由AI设计并核对，**不是人工盲标**。Gold 是具体父段落锚点，没有穷举所有同样可支持回答的段落，因此报告叫“锚点召回/排名”；没命中锚点不必然意味着所有结果无用。中英文问题共享12个主题，不是24个独立主题。

`evals/bge-literature.mjs` 运行实际 `retrieveAll`：topK=5，不调用查询改写LLM，不启用重排，不调用外部检索；语言输入原样保留。窗口hash基线和BGE用相同窗口与父ref体系。语义运行前强制验证服务 ready、model、固定revision、1024维、verifiedWeights、权重SHA，以及索引无陈旧指纹。任何通道失败都会把报告标为failed并统计coverage，不能当成功语义结果。

语料内容 LF SHA：`a77bdcc2e86ae79dac7e6672307bbb803b9a7d32a53922647334e3a7efc22285`。BGE revision：`5617a9f61b028005a4858fdac845db406aefb181`；真实权重SHA：`b5e0ce3470abf5ef3831aa1bd5553b486803e83251590ab7ff35a117cf6aad38`；公共索引SHA：`efb32908e693cd76ea20a88f0e93e5bd44839c00eae9af8800c05fedee7decc6`。

## 实测结果

| 检索配置 | 锚点 Hit@5 | 锚点 MRR@5 | 锚点 nDCG@5 | 命中且非weak | 无证据识别 | P50 / P95 |
|---|---:|---:|---:|---:|---:|---:|
| 词法 | 66.67% | 0.4854 | 0.5303 | 62.50% | 2/4 | 16 / 23 ms |
| 词哈希向量 | 29.17% | 0.2028 | 0.2245 | 29.17% | 3/4 | 3 / 3 ms |
| 词法 + 词哈希 RRF（hash权重0.3） | 66.67% | 0.4396 | 0.4946 | 54.17% | 3/4 | 17 / 27 ms |
| BGE dense | 70.83% | 0.5521 | 0.5914 | 54.17% | 3/4 | 129 / 157 ms |
| 词法 + BGE RRF（dense权重1） | **83.33%** | **0.6354** | **0.6856** | **75.00%** | **2/4** | 154 / 178 ms |

五项均28/28通道成功，引用偏移与来源元数据完整率1.0。这里的 modelCalls=0 指没有生成式LLM调用；两个语义配置各自真实执行28次查询嵌入。服务采用CPU，查询期间未占用Qwen训练GPU。

相对词法+hash，BGE混合检索的锚点Hit@5增加16.67个百分点、MRR增加0.1958；24个正例中11个排名改善、2个下降、11个不变。下降的两题均围绕 iff：中文锚点从第5跌出前5，英文从第1变第3。不能只报告平均提升而隐藏退化。

**无证据判定仍有缺口**：天气负例从weak变成非weak；Qwen/MMLU实时成绩题在两种混合配置中均没有正确标weak。原有weak是词面/概念覆盖启发式，BGE相关性不是事实支持证明。本轮没有针对这4题调阈值，也没有声称BGE使拒答更可靠；检索器启用策略与答案支持审核必须保留这一风险。上述只是检索/可定位性结果，没有生成并评判真实回答的正确率。
