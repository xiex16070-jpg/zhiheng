## 上下文统计与压缩

参考 [dsh-context 官方说明](https://github.com/bowenliang123/dsh-context/blob/main/README.md) 的逐请求组成、时间范围、工具/技能活动和压缩事件呈现，未安装或复制该插件。其界面可观察宿主压缩，本项目的压缩实现仍由自己的 `context.mjs` 执行。

入口：设置 → 上下文洞察，或主输入框输入 `/context`。支持 7 天、30 天、全部及当前会话；请求趋势可返回所属会话。数据限定当前用户最近 300 个任务、250 条可见请求。服务商输入、输出、缓存用量取实际 `usage`；没有返回则标记缺失，绝不用字符估算冒充账单。未配置可信单价，不估算费用。旧任务没有逐请求记录，不补造历史数据。

每次模型请求记录系统提示、工具定义、用户消息、注入资料、模型回复、工具结果六类估算量；额外展示输出预留、最大工具定义、失败重试耗时和压缩/清理事件。中文参数与 schema 使用与正文相同的字符估算。主任务、辅助和 API 子代理调用通过 AsyncLocalStorage 关联到任务；CLI 内部多轮细节不可观察，单独保留团队调用记录，不能假称与宿主请求等价。

统计层只保存数量、名称、耗时、项目和任务 ID，不另存问题、原文、工具参数或密钥。文件活动沿用当前用户已有产物路径；普通会话和团队运行记录仍各自保留其既有内容，不能把“统计元数据不复制正文”理解为应用完全不保存对话。

压缩改进：

- 软预算计入工具 schema 和输出预留；本地 Qwen 独立保持 4096 的现有配置。
- 微压缩保留工具名和允许的文件/ref 定位字段，明确旧结果不是批准或重新执行指令。
- 保持 assistant/tool 协议配对与最近原文；若生成摘要比原上下文更长，回退确定性裁剪。
- 使用已有辅助调用预算；钩子、次数、压缩事件和拒绝状态继续可追溯。预算是估算软限制，不能替代服务商实际模型窗口。

## 团队与结论

- 团队机制、逆向来源与本机实测：多角色独立 API/模型、主连接与受控本机 CLI。模型可直接使用 `delegate_task`，预算和只读边界不因成员增多而放宽。
- 知识结论与 Hermes learn：来源哈希、对话身份、定期回源、语义审查预算、状态流转与检索门槛。不能承诺模型永不出错或记忆永不遗漏。
- 单文档研究显式绑定文档，编辑提问保留来源；侧栏原有分区偏好不被覆盖。单文档范围不允许后台转移或外部检索绕过。多文档结论继续研究保持原有范围，缺来源时要求报告缺口。

## 配置与回滚

新增运行设置保存在 `data/runtime-settings/<uid>.json`，默认回退到环境变量只发生在文件不存在时；损坏文件拒绝读取和覆盖。团队凭据使用现有加密凭据机制。新配置/结论/运行产物目录已排除 Git。

`GET/POST /api/runtime-settings`，`POST /api/runtime-settings/test`，`GET /api/context-insights?days=7&conversationId=…`。设置写入要求已签名本机身份、同源 JSON 与 `x-settings-request:1`，模型工具无保存权限。按用户关闭团队、桌面浏览器、命令或学习审查即可关闭对应入口；原资料、旧会话和已有文件不因关闭开关删除。
