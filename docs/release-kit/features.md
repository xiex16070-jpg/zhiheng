# 知衡功能手册

**v3.1.0 Beta** · 对应源码 `420b373`。知衡是本地运行的中文 Agent 工作台。Agent 模式围绕项目交付，知识库研究模式围绕原文和引用。两种模式共用项目、模型配置和工具权限。

阅读下面的状态时，**本轮实测**指在隔离环境打开真实界面、调用本机服务并检查结果。演示对话由本地脚本提供模型响应，工具、审批、文件、检索和页面走应用的实际链路。**已有验收**引用仓库随版本保存的报告。**待验证**表示仍需要相应的账号、服务、设备、材料或人工复核。

## 从一个任务开始

1. 从 [Windows 版发布页](https://github.com/xiex16070-jpg/zhiheng/releases/tag/v3.1.0-beta.1) 下载 x64 ZIP，解压后双击 `Zhiheng.exe`。启动器负责启停服务，工作台在默认浏览器中打开。开发者也可以用锁定的 Node.js 依赖从源码启动。[Windows 使用与数据目录](../windows-release.md)
2. 右上角点击模型按钮，选预设或填 OpenAI 兼容地址和模型名。用“测试连接”确认对应端点可访问。模型是否支持工具调用、视觉以及结构化输出取决于服务端和具体模型。更换后应重测实际任务。
3. 左栏“项目”旁的加号可以选择本机文件夹。项目按文件夹组织会话和文件，切换项目会改变后续任务的范围。打开旧产物时仍按它原来的项目读取。移除项目会移出侧栏，磁盘文件由用户管理。添加本机目录使用 Windows 文件夹选择器。
4. 左上选择 **Agent** 或 **知识库研究**。前者适合“读取这个项目，整理一份演示稿”。后者适合“教材怎样定义霍尔三元组？给我原文依据”。发送前确认输入框上方的项目和资料范围。研究问题索引按当前范围变化，也可以手动刷新。

**状态**　Windows 11 x64 的包和两种模式已有验收。本轮覆盖了临时项目、两种模式和 Chromium 390 px 窄屏。真实模型需在使用者的环境另行验证。Windows ARM64 和 macOS 桌面包未提供。

## 从本地资料扩展到外部来源

在“设置 → 网站与学术”可分别保存网站搜索与学术源配置。“测试连接”反馈该提供方的响应，服务之间的状态独立。模型只有在任务范围和工具权限允许时才会使用外部结果。联网搜索查询、模型输入以及获批的 MCP 参数会发到各自配置的服务，请在确认前查看内容。

“设置 → 回答偏好 → 联合研究”可以选择本地和外部证据的组合。权重用于给两组来源分配候选名额。阅读答案时先看本地与外部各找到了多少证据，再核对具体出处、日期和可取得的正文。外部服务不可用时可出现部分成功。

- Tavily 需要有效 Key。OpenAlex 受账号配额约束，Europe PMC 等来源可能独立失败或限流。本轮展示真实设置界面，未重测这些服务。
- “设置 → 研究集成 → 文献库”连接本机 Zotero。开启 Zotero 的本地 API 并按需填写授权后，可以搜索已有条目并把选中的元数据导出为 BibTeX。当前界面可配置，本轮未连接真实 Zotero 数据库。
- Context7 在“设置 → MCP 与工具”有固定服务入口。连接后选工具，版本化文档查询逐次审批。已有匿名实测，配额、版本覆盖和后续可用性以服务响应为准。[联合研究说明](../joint-research.md)

## 推理与规则验算

左栏“知衡推演”提供两个入口。**文献推理**选择后续对话如何组织检索。**规则验算**对给定事实和规则求解并生成证明。两条链路的结果要结合各自的前提理解。

| 选择 | 适合的任务 |
| --- | --- |
| ReAct | 需要读取多个原文或工具结果的任务。模型根据上一轮返回决定是否继续取证。 |
| IRCoT | 问题涉及多个线索时，围绕已有中间证据做有限的迭代检索。 |
| Tree of Thoughts（ToT） | 有多条候选解释或检索方向时，分支比较后保留有限的候选。 |
| 分层正向 | 对分层规则逐轮推出结果。适合检验简单规则集。 |
| 半朴素增量 | 对递归规则重点传播新生成的事实，减少重复推导。 |
| 查询导向 | 从待验证的谓词和对象出发，缩小需要求解的范围。 |

HanLogic 规则使用“若……则……”“只有……才……”“非”“除非”等写法。查询可以得到成立、否定、未知、冲突四类状态，还能查看推导和真正在程序里使用的事实。界面运行内置示例，自定义程序可使用 `.han` 文件和 CLI。研究对话抽取到的前提应人工核对，验算只对给定程序成立。本轮运行了真实规则示例。三种文献策略的相对质量仍需同条件测试，GraphRAG 属于后续可探索的研究扩展。[语言说明与 CLI 示例](../hanlogic.md)

## 记忆、技能、插件与运行记录

- **学习与记忆。** 从左栏“学习”审核建议，查看环境事实、用户画像、技能和记录，可固定、撤回或归档适用条目。保留稳定工作偏好有助于跨会话协作。知识结论与用户画像分开管理，模型建议带来源和条件。长周期画像稳定性仍需真人使用复核。
- **技能。** 技能写在 `SKILL.md` 中，用简短说明协助任务匹配，也可通过输入区“更多操作”选择。用户技能、内置技能、固定与归档状态分别处理。可导出 Agent Skills ZIP。长描述或附件可先从“设置 → 研究集成 → 插件包”预检。安装规则和可带出的内容见[社区指南](community.md)。
- **MCP 与插件包。** 本地 stdio 与 Streamable HTTP 连接独立注册，先发现工具，再选启用项。连接、工具、资源、外发和写操作受各自的授权规则。插件包装载个人技能并保留 MCP 配置草案。用本轮社区示例可以在本机验证预检、导出与连接。
- **上下文与监控。** “设置 → 上下文”显示会话预算及整理状态。旧检索摘录可被归档或压缩，恢复任务时保留审批绑定的状态。运行监控可核对记录。可选的 Langfuse 记录耗时、步骤和错误分类。真实实例的历史验收在[追踪说明](../langfuse.md)，此处截图未重连。
- **环境与偏好。** 设置顶部导航可跳到界面、权限、命令、上下文、团队、审核、搜索、MCP、研究集成和回答偏好。支持浅深主题、减少动效、开屏开关，知识库范围、引用要求和推断偏好按用户保存。语音听写取决于浏览器与麦克风权限。
