# 社区扩展与贡献

**面向 v3.1.0 Beta。** 独立技能、MCP 和测试材料是贡献入口。表格列出当前可用接口、适合交给社区的改造和验收条件。

## 已有的自定义入口

| 扩展面 | 今天能改什么 | 用什么验收 |
| --- | --- | --- |
| 个人技能 | 编辑任务触发说明、步骤、交付格式和复查要求。可发布一个标准 `SKILL.md` 目录，并用 Git 管理版本。内置模板作为源码贡献提交。 | 同一组提示词覆盖应触发和不应触发的任务。做隔离用户预检、安装、导出回读。引用模板从原始文献取值。 |
| 声明式插件包 | 一个 `plugin.json` 可组合若干技能和 MCP 连接草案。使用者在自己的项目内预检、安装、连接、选授权工具。 | 确认预检前后技能和插件数量一致。安装仅进入当前用户，卸载保留经用户改写的内容。单独测试连接和工具调用。 |
| 自定义 MCP | 可对接可信的本地 stdio 程序或 Streamable HTTP 服务。支持工具目录、参数校验、按工具启用，以及另行授权的资源。 | 描述参数、数据去向、权限和可预计的副作用。分别复验断线、取消、越权拒绝、参数变化、缺字段和兼容协议。 |
| 模型与团队 | 自定义 OpenAI 兼容端点。角色可选当前模型或另一个已配置模型，填写职责及调用预算。 | 记录地址类型、模型版本和声明/实测能力。用同一任务和前态对照工具调用、引用和最终结果。 |
| 搜索、语料与可选服务 | 配置 Tavily、学术来源、RAGFlow、向量库、embedding、重排和 MinerU 等已有接入点。可提交授权语料或真实故障样本。 | 检查索引模型身份、原文定位、权限过滤和超时回退。用有引用正例、缺证据负例及留出集对照。 |
| 主题与交互 | 在源码调整 `src/styles/tokens.css` 主题变量、`src/ui/icons.js` 图标及现有界面组件。 | 浅色、深色、390 px、键盘、减少动效、长标题和大量证据都能操作。使用同一语义色和焦点规范。 |
| 评测与报告 | 在 `evals/` 补检索、文献、模型适配和 PDF 评测。可在本机协议夹具或公开语料上做 PR。 | 公开可运行命令、样本来源和许可，分开标注真实、模拟、跳过和待人工核查。 |

### 技能与插件包入门

使用仓库的[证据复查插件样例](../../examples/community/evidence-desk-pack/plugin.json)。把整个 `evidence-desk-pack` 目录复制到一个临时项目，在知衡打开这个项目。

1. 打开“设置 → 研究集成 → 插件包”。在“工作区相对路径”填 `evidence-desk-pack`，点“只读预检”，检查技能名称、描述和适配提示。
2. 将路径改为 `evidence-desk-pack/plugin.json`，确认清单内容后点“安装插件包”。此例只包含一项个人技能。
3. 打开“学习 → 技能”，查看 `evidence-desk-check`，下载 Agent Skills ZIP。解压后可把 `evidence-desk-check/` 放回临时项目预检。

知衡的技能包安装器当前要求简短描述，最多 60 字符，另有正文大小约束。标准 Agent Skills 的描述上限为 1,024 字符。预检会列出可见的附属目录和兼容问题，当前安装器只导入技能入口的正文和元数据，导出也只带可见的技能入口。开发者发布带 `references/`、`scripts/`、`assets/` 的技能时，应先在文档说明哪些内容需要手工处理。清单里的工具声明只提供信息，工具权限由连接和审批流程控制。[Agent Skills 规范](https://agentskills.io/specification)

### 自定义 MCP 入门

[只读术语表](../../examples/community/glossary-mcp.mjs)依赖项目锁定的 MCP SDK。服务器用固定词表回答两条术语请求。

1. 在安装了依赖的源码目录执行 `node -p "process.execPath"`，取得 Node 可执行文件的绝对路径。执行 `(Resolve-Path examples/community/glossary-mcp.mjs).Path`，取得脚本的绝对路径。
2. 打开“设置 → MCP 与工具”，添加本地进程连接。将可执行文件填入命令字段，参数单独填为 `["脚本的绝对路径"]`。JSON 中的 Windows 路径可用正斜杠。查看源码后测试连接，检查目录是否列出 `lookup_term`。
3. 只启用 `lookup_term` 并保存。配置好自己的模型后，可以要求“使用社区术语表解释‘证据不足’”，核对即将传给工具的参数并批准。实际返回包含词条定义。示例也可通过 SDK 客户端验证，无模型账号依赖。

连接 stdio 会启动程序。进程具有当前系统账号的权限。提交第三方连接时请附可审阅实现、安装方式和最小凭据范围。HTTP 的远程服务使用 HTTPS，回环地址可用 HTTP。把 token 填进连接专用字段。工具目录和运行结果都可能变化，启用前应检查其声明及真实行为。[MCP 传输规范](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)

## 建议优先开放的改造

| 优先级 | 社区可做的任务 | 代码入口与合并条件 |
| --- | --- | --- |
| P0 | **技能目录的无损交换。** 先完善前置摘要与长描述的映射，再为 `references/`、`assets/` 增加只读登记、来源哈希和可选完整导出。用 Impeccable 等合法样本测长描述、引用层级及可读提示。 | `src/server/{skill-preflight,agent-skill-format,skills,skill-library}.mjs`。预检零副作用。附件可按用户、引用路径和大小检查。脚本只显示并由用户另行处理。 |
| P0 | **连接器示例与兼容矩阵。** 由社区维护文献库、术语、数据目录、开发文档和 LSP 的 MCP 连接示例。每个条目填协议、版本、来源许可证、网络范围、费用和写工具情况。 | `src/server/{extensions,extension-network,mcp-sdk,plugin-packs}.mjs`。本地 fixture 和官方协议相关子集可重复。条目发布和启用权限各自独立。 |
| P0 | **模型底座的能力合同。** 用固定样本和错误注入测模型的工具参数、多轮回复、结构化输出和空回答。完善版本失效规则。保留 Qwen、小模型、各兼容 API 的不同证据。 | `src/server/{llm,backend-capabilities,model-connections,local-qwen}.mjs`、`evals/model-pairs.mjs`。原始输出、解析和执行分别计分，真实调用由贡献者自己控制。 |
| P0 | **公开可复查的讲义和留出样本。** 招募能核查计算机论文、教材和扫描页的人，补上来源、支持或反驳、段落/页码及分歧仲裁。 | `evals/annotation-*.mjs`、`evals/pdf-pages.mjs`。来源许可与人工标注身份明确，真实样本跟模拟样本分开。保留原图和模型评估的范围边界。 |
| P1 | **版本化检索与解析适配器。** 将检索返回的证据片段、文档解析返回的正文及位置整理成接口和契约样例。优先支持社区语料/连接器、MinerU 分页以及不同重排服务。 | `src/server/{retrieve,vector,rerank,ragflow}.mjs` 与 `src/server/extract/`。适配器声明语料许可、语言、坐标系、版本、限流和回退。重建失败能保留旧索引。 |
| P1 | **规则与推理工作台。** 开放 `.han` 案例集、证明视图、反例和中文谓词模板。把策略的输入、预算和输出事件整理成可对照合同，供研究者实现候选策略。 | `src/logic/`、`src/server/{logic-runtime,research-strategies}.mjs`。独立小规则真值断言、证明稳定性、终止预算和冲突例齐全。GraphRAG 如有贡献，先作为离线对照。 |
| P1 | **知识库底座与界面主题。** 先把文件、MySQL、缓存和任务断点的职责写清，抽取最小接口后再扩展存储或索引。社区可以先提交主题、导航和可访问性改进。 | `src/server/{store,db,cache,workflow-journal}.mjs`、`src/ui/configuration-sections.js`、`src/styles/tokens.css`。两用户隔离、保存原子性、恢复及前端焦点通过回归。 |
| P2 | **经审阅的插件索引与流程。** 规划面向社区的静态目录，列出版本、来源、说明、所需工具及许可证。共享流程先由技能和 MCP 组成，后续评估声明式流程节点及受信任的开发者 hook。 | 当前 `src/server/hooks.mjs` 是内部事件机制，`plugin.json` 接受声明数据。新接口应支持撤回、版本失效、限额和审批续接。带代码执行的入口须由系统隔离和用户权限控制。 |

社区可以提议接口的实现方式。默认权限、签名身份、属主校验、外发审批、脱敏、结论回源和命令边界属于兼容条件。功能支持应附实际输入和输出。界面显示“能配置”“连通”和“已验证该功能”时，应各有对应的证据。

## 可直接开始的任务

- 用现有样例为三种常见运行环境写自定义 MCP 安装说明，给出工具发现和调用的最小复现。
- 给一个带附件的标准技能补预检兼容用例，记录当前会保留哪些文件及导出是否可回读。
- 用有许可的两页 PDF 标注正文、标题、表格和阅读顺序，提交预期 Markdown 及回源坐标。
- 贡献一个公开的模型/工具失败样本和匿名结果，按同条件对比记录原始输出、解析结果和任务结果。
- 从浅色、深色和移动端各选一个真实界面，补长文本、键盘操作和空状态。随 PR 提供前后图。
