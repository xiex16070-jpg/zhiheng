# 模式入口、设置分区与能力导航

本轮按用户截图修正入口层级、空白会话的模式表达和独立审核表单。复用原有插画与品牌符号，不增加动画依赖，也不更改开屏序列。

- 模式选择从输入框上方移动到顶栏左侧，改为带滑动选中底板、图标和简短用途的双选按钮。小屏使用顶栏第二行，两个模式始终可见；按系统减少动态效果设置关闭过渡。
- Agent 新会话显示已有三角协作图；知识库研究显示已有图书插画和研究问题索引。修复新建会话强制切回 Agent 的行为，保留用户当前选定模式。切换模式保留输入草稿，已有聊天内容不重绘。
- 设置顶部提供 11 个固定分区入口，正文独立滚动，支持当前分区高亮、键盘定位、直接跳到命令/数学排版等具体控件。分区标识与能力导航共用 `configuration-sections.js`。
- 独立证据审核改为连接、预算、调用说明和操作栏。接口、模型、密钥及数值输入统一对齐；读取/保存期间禁止重复提交，显示未保存状态。沿用现有属主隔离、修订号与密钥留空保留语义，不在浏览器回填密钥。
- 能力导航加入配置直达目录，定位审核、团队、上下文、权限、网站与学术搜索及集成等已有功能；配置入口不代表该能力已经启用或完成外部实测。验证结论入口也能切换已经打开的知识面板，普通重开则保留当前页面与筛选。

主要实现为 `src/ui/app.js`、`configuration.js`、`configuration-sections.js`、`judge-settings.js`、`capabilities.js` 及 `src/styles/mode-navigation.css`、`settings-workbench.css`。生成样式通过 `npm run build:ui` 统一打包。
