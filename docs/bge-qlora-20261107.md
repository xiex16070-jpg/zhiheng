## 固定对照设计

新增 `evals/bge-literature-cases.json` 在观察 BGE 结果前冻结：24 个中英正例、4 个无证据问题。标签由 AI 编写并逐项核对真实原文锚点，不是人工盲标。只认可指定锚点会低估其他有效段落，不能把它当成完整文献相关性标注。

五个变体使用相同语料、问题、top-5 和引用校验：词法、哈希向量、词法+哈希、真实 BGE 向量、词法+BGE。关闭查询改写和重排，独立记录召回、排序、无证据识别、引用偏移、延迟和每题通道错误。语义变体必须通过真实权重健康、模型版本、维度与索引指纹检查。

Ragas 使用实际检索得到的父引用 ID 评估 precision/recall。修复了“正例空检索被排除在分母外”的统计缺口：现在计为零召回，并明确空集 precision 的零值约定；无证据题单列，不混入正例均值。用实际 Ragas 0.4.3 对一命中、一漏检、一无证据的输入核对，正例均值为 0.5，未虚构回答或语义裁判结果。
