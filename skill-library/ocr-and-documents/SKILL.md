# 文档读取策略

## 先判断
1. 用 read_document 读一次，看返回字数与 kind。
2. 字数极少（<200 字）且页数不少 → 大概率是扫描件（无文字层）。
3. 出现大量替换符/乱码 → 编码或字体映射问题。

## 回退顺序
- 扫描件：提示用户提供 OCR 版本，或改用 MinerU 解析（若部署开启）；不要凭空「读图猜字」。
- 分栏/表格错乱：按章节分段读，读一段核对一段，不整篇硬读。
- 超长文档：先读目录/摘要，再按子问题定位章节，避免一次塞满上下文。

## 引用
- 引用 PDF 时给出页码或章节标题；字符区间只在有文字层时可信。
