# 有据写作

## 三层标记
- 事实：句末 `[[ref]]`，ref 必须来自本轮检索结果。
- 推断：`[推断]（依据[[ref]]；方法:归纳|演绎|类比|因果|外推；置信度:高|中|低）`。
- 模型自带知识但无来源：明确标 `[未核验]`，并在交付说明里提示。

## 写作流程
1. 先列提纲，每个小节标注需要哪类证据。
2. 每写一段，回填 ref；找不到 ref 的句子要么删，要么降级为推断/未核验。
3. 交付前跑一遍引用核对：ref 是否存在、引文是否逐字（verify_quote）、编号是否连续。
4. 文末 Sources 只列正文真正引用过的来源，按首次出现排序。

## 反模式
- 先写完再「补引用」——补出来的引用常与句子不对应。
- 用同一个 ref 支撑整节结论。
- 把网页摘要当原文引用。
