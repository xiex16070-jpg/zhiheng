# 盘点一周承诺并制定可执行的下周计划

1. 明确回顾区间、时区和用户提供的记录范围。
2. 汇总承诺、完成成果、延误、取消和未决事项。
3. 把可核实完成与自报进度区分，不虚构百分比。
4. 找出重复阻塞与依赖，不将个人评价当事实。
5. 对逾期任务重新检查价值，建议继续、拆分或取消。
6. 下周计划按优先级与可用时间限制总量。
7. 每项写清下一个动作与可观察的完成条件。
8. 保留日常工作与意外事项的缓冲时间。
9. 需要外部协调的工作先列为待确认。
10. 不因周计划自动创建长期定时任务。
11. 交付一页回顾与少量重点行动，记录关键假设。
