# 参考文献导出

## 规则
1. 只使用引用快照中已有的元数据。缺作者、年份或 DOI 就省略。样式可按规范显示无年份标记。
2. 中文文献用 GB/T 7714：作者. 题名[J]. 刊名, 年, 卷(期): 页码.
3. 英文文献保持原文大小写与作者顺序，作者超过 3 人用「等/et al.」。
4. 每条文献后附内部 ref，便于读者回跳；导出清单不重复列未被正文引用的文献。
5. 输出顺序与正文首次引用顺序一致（顺序编码制），不按字母重排。

## 交付
- 回答下方的「引用清单」复制可读文本。「导出参考文献」从已保存的引用生成 CSL-JSON、BibTeX、RIS 或按正文编号的 APA 文本。
- 导出保留内部 ref 和首次引用顺序。使用摘要、网页摘录或预印本时保留相应说明。用户明确要求本机 Zotero 条目时使用已启用的 Zotero 导出入口。
