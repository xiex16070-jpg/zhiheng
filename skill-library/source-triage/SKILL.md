# 来源分级

## 分级
- A 级：同行评议论文、标准、官方统计、监管文件。可直接作为结论依据。
- B 级：预印本、会议论文、权威机构报告。可用，但结论要标注「预印本/未经同行评议」。
- C 级：厂商文档、新闻、百科。只用于事实性细节（版本号、发布时间），不用于学术结论。
- D 级：论坛、自媒体、营销页。默认不引用；确需引用时明确写「非权威来源」。

## 判据
- 看它是否回答你的子问题，而不是看它是否出现关键词。
- 同一结论至少两个独立来源；单一来源的强结论要降级措辞。
- 注意年份与版本：材料/算法类结论 5 年就可能过时，引用时带上年份。
- 摘要与正文冲突时以正文为准；只读到摘要就说明「仅依据摘要」。
