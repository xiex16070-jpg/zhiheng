# 研究报告

## 结构
1. **执行摘要**（3-5 句）：结论、依据强度、最重要的限制。
2. **背景与问题**：为什么现在要回答它。
3. **发现**：按问题分节，每节「结论句 + 证据 + 数字」。
4. **局限与不确定性**：样本、口径、时间范围、来源等级。
5. **建议/下一步**：可执行、可验证。

## 数字纪律
- 每个数字带单位、口径、时间与来源（ref）。
- 百分比写清基数；「提升 12%」与「提升 12 个百分点」不混用。
- 推算值单独标注推算方法与假设。

## 呈现
- 小节标题写结论（「高镍正极循环衰减主要来自表界面副反应」），不写「结果分析」。
- 表格优于长段落罗列；图表标题即结论。
- 不用「显著」除非有统计检验。
