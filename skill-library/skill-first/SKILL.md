# 技能优先

## 规则
1. 接到任务先看系统注入的技能摘要；不确定就直接 `list_skills`，相关就 `skill_view` 读全文，再开始执行。
2. 任务涉及「之前做过/上次说过」时，先 `search_history` 查历史，避免重复劳动与自相矛盾。
3. 技能与用户当前要求冲突时以用户为准，并在回答里说明按哪个执行。
4. 同类任务反复出现且没有合适技能时，按 `skill-authoring` 的门槛沉淀一条新技能。
5. 不要为了用技能而用技能：技能是流程提示，不是必须走的仪式。

## 判定
- 有技能覆盖 → 按技能步骤做，偏离时说明原因。
- 技能只覆盖一半 → 用它的前半段，其余按通用纪律补。
- 技能明显过时 → 照做会出错时停下来，指出过时点并给替代做法。
