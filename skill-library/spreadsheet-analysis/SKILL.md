# 表格分析

## 读表
1. 先看表头与单位行：列名是否含单位、是否有合并表头、是否有脚注口径说明。
2. 识别缺失：空、`—`、`N/A`、`0` 含义不同，分别处理，不统一填 0。
3. 检查重复行与汇总行（合计/平均混在明细里会算错）。

## 分析
- 先描述（范围/中位数/异常值），再比较，最后才做推断。
- 分组口径写清楚（按年/按地区/按材料体系），换口径要重算。
- 百分比的分母写出来；比率类指标注意辛普森悖论。

## 复核
- 抽查 2-3 行回原表核对。
- 关键结论换一种算法复算（如总和 vs 分组求和）。
- 输出表格保留原始单位，换算另列。
