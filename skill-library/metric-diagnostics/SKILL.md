# 分析指标异常并区分相关性与因果证据

1. 先核对指标定义、时间范围、分母和数据刷新。
2. 排查重复、缺失、口径变更与采集故障。
3. 用同周期基线比较，考虑季节性和样本量。
4. 拆分总体变化与人群、渠道、产品等结构变化。
5. 优先分析变化贡献最大的部分。
6. 检查同期发布、运营、外部事件和数据延迟。
7. 将解释写成待检验假设，并寻找反例。
8. 相关趋势不直接证明因果，说明混杂因素。
9. 需要实验时列明分组、护栏和停止条件。
10. 证据不足时给出下一步查询而非确定归因。
11. 交付包含影响规模、最可信解释与待确认因素。
