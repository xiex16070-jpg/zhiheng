# 综述对比矩阵

## 做法
1. 先定 3-5 个对比维度（对象/方法/数据/结论/局限），维度来自用户问题，不要套模板。
2. 每篇文献占一行，每个单元格只放「该文献明确说了什么」，没说不填「未提及」三个字。
3. 矩阵建完再写正文：先写共识（≥2 篇一致），再写分歧（按维度归因：样本/方法/年代），最后写空白。
4. 分歧不要强行调和；写清「A 与 B 结论相反，差异可能来自 X」，比「各有道理」有用。
5. 表格里的每个论断后面带 ref；表格放正文前，结论放表格后。

## 常见错误
- 把不同维度的结论放在同一列比较。
- 用「综上所述」掩盖没有共识的事实。
