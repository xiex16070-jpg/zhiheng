# 文档 → 行动项

## 抽取对象
- 义务：「应/须/不得/负责」引导的句子。
- 时限：日期、期限、「自发布之日起 N 日」。
- 角色：谁负责（部门/岗位），没写就标「未指定」。
- 交付物：报告、备案、验收等可验证产物。

## 输出格式
| 行动 | 责任人 | 截止 | 原文依据（引文 + 位置） |

## 纪律
1. 每条行动项必须有原文引文，不能概括成「加强管理」这类空话。
2. 相对时限换算成绝对日期，并注明推算依据。
3. 文档没写的不要补；不确定的放「待确认」区，不混进正式清单。
