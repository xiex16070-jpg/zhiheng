# 逐字引文核验

## 规则
1. 任何加引号的句子，必须先用 verify_quote 校验通过再写入答案。
2. 校验失败不外乎三种原因：字符区间不对、标点/全半角差异、模型改写。前两种换成检索返回的原句片段；第三种改为转述并保留 ref。
3. 引文长度控制在 1-2 句：太长容易跨段错位，也无法定位。
4. 中文引文保留原文标点；英文引文保留原大小写与连字符，不要「顺手修正」。
5. 一处引文只支撑一个论点，不要把同一句引文挂在三个结论后面。

## 交付话术
- 校验通过：正常引用。
- 校验失败但语义可信：「据该作者的论述（大意）……」+ ref，不加引号。
- 完全找不到原文：删掉该句，不要凭记忆补。
