# 证据缺口

## 什么时候写
- 用户问的是「趋势/前景/最优方案」，而检索只覆盖了某一年份、某一材料体系或某一地区。
- 多篇文献结论一致但样本高度同源（同一课题组/同一数据集）。

## 怎么写
1. 先陈述已覆盖的范围（年份、对象、方法），再写未覆盖的部分。
2. 缺口要具体到可检索：「缺乏 2023 年后 NCM811 在 45℃ 以上循环的数据」，而不是「研究不足」。
3. 给出 1-3 个下一跳检索式（含同义词），让用户能自己继续。
4. 缺口不改变已有结论的措辞强度——已有证据支持的部分照常下结论。
