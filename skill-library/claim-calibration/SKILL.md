# 措辞校准

| 证据状况 | 用什么措辞 |
|---|---|
| 多篇 A 级来源一致 | 「研究表明」「可以认为」 |
| 单篇 A 级或少量 B 级 | 「有研究显示」「一项针对 X 的研究发现」 |
| 仅摘要/二手转述 | 「据摘要」「据该综述转述」 |
| 机制推断（无直接实验） | 「可能」「一个合理解释是」+ 标为推断 |
| 无证据 | 直接说没有查到，不写「一般来说」蒙混 |

## 禁令
- 不用「显著」「证明」「必然」描述相关性证据。
- 不把「未发现反例」写成「已被证实」。
- 数字必须带单位和口径（「提升 12%」→「容量保持率提升 12 个百分点（1C，200 圈）」）。
