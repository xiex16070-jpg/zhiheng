# 按数据含义选择图表并校验标注

1. 先说明图表要回答的问题与受众。
2. 比较大小优先条形，趋势用折线，关系用散点。
3. 组成比例只在分母明确且类别少时使用。
4. 保持时间、单位、统计口径和数据粒度一致。
5. 缺失值、估算值和采样结果应明确标记。
6. 条形图原则上从零起，其他轴截断需说明。
7. 不使用三维透视夸大差异。
8. 颜色表达稳定含义，同时提供文字或符号。
9. 标题写出范围，注释解释关键异常与限制。
10. 只用有来源的数据，禁止为视觉效果编造数值。
11. 交付前核对汇总、轴刻度、图例与小屏可读性。
