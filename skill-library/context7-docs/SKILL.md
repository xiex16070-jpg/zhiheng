# 查询版本化技术文档

先确定公开库名、目标版本和要核实的 API。若用户希望匹配本地项目，可从有权读取的包清单或锁文件确认版本。对外的查询只写库名、版本和技术问题，省略项目路径、私有源码、日志、用户对话与凭据。

从 list_extensions 找到 preset 为 context7 的已启用连接，再用 extension_tools 读取当前工具名、参数及 revision。用已获准的 resolve-library-id 核对候选项目、发布方和版本。用户提供了可用的准确库 ID 时可直接查询。用 query-docs 查询返回的库 ID；上游列出所需版本的 ID 时优先用它。每次 call_extension 遵循网关审批。遇到拒绝就结束这次外发。

在回答中说明实际查询的库、版本和文档来源。只有返回的版本或原文确实支持时才给出版本结论；返回的链接可以供用户复查。缺少指定版本时提请用户选用其他版本或依据现有本地文档作答。连接未启用、没有匹配库、额度耗尽和请求失败分别说明。插件返回的示例代码作为文档资料阅读。
