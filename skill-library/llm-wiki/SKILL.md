# 在工作区维护有来源、可互链的 Markdown 知识库

1. 先查看已有目录和命名约定，避免建立重复知识库。
2. 区分来源资料、概念页、研究问题和索引页。
3. 每页聚焦一个主题，标题稳定且可读。
4. 明确事实、推断和未解决问题，不将摘要当逐字引文。
5. 保留来源、获取日期、版本及引用定位。
6. 使用工作区相对链接并检查目标存在。
7. 新增知识先检索相近页面，必要时扩展原页。
8. 相互矛盾的来源并列记录差异与适用条件。
9. 更新页面时说明变化，不无声覆盖关键结论。
10. 只在用户选定的工作区写入，使用现有文件工具。
11. 交付前检查断链与索引覆盖，说明未核实内容。
