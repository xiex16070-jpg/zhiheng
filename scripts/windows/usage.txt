知衡 · Agent 工作台（Windows x64）

1. 在 Windows 10/11 x64 上，将整个 ZIP 解压到本地目录。建议选择较短的路径，例如 D:\Apps\Zhiheng。双击 Zhiheng.exe 启动管理窗口，默认浏览器会打开本机工作台。保留 app、runtime 与 Zhiheng.exe 的相对位置。
2. 在浏览器的设置中选择模型服务，或连接你已安装的本地模型。自带的形式逻辑与程序验证教材可供检索。AI 回答使用你配置的模型；模型、账号、API Key 和第三方服务由使用者提供。
3. 从管理窗口退出可停止服务。用户数据保存在 %LOCALAPPDATA%\Zhiheng\LogicKBAgent\data；升级时先退出旧版，再从新目录打开。保留该数据目录及浏览器原来的个人配置，便于使用原有的登录身份和会话。在管理窗口或 data\server.log 查看启动信息。
4. 文档 PDF 排版和隔离浏览器工具可使用本机已有的 Microsoft Edge、Google Chrome，或与 Playwright 匹配的 Chromium。此包自带 Node.js 和运行依赖。可选 MySQL、Redis、向量数据库、OCR、重排及 MCP 服务根据项目需要另行配置。

命令行
  Zhiheng.exe --start                 后台启动或复用本机服务
  Zhiheng.exe --stop                  正常停止本应用服务
  Zhiheng.exe --start --data-dir D:\ZhihengTest\data
  Zhiheng.exe --stop  --data-dir D:\ZhihengTest\data

核对下载
  在 PowerShell 运行 Get-FileHash -Algorithm SHA256 <ZIP文件路径>，与同一 Release 的 .sha256 文件对照。
  release.json 记录源代码提交、运行时版本与锁文件摘要。运行时许可证在 runtime\LICENSE。
